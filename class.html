學生名單 — 班級個人資料（20 欄）

欄位完全對應 Excel「班級個人資料」：科別、姓名、班級、座號、學號、性別、身分證、報名身分別、經濟狀況、出生年/月/日、西元出生、畢業國中、家長姓名、學生手機、家長手機、電話、郵遞區號、地址。點「詳情」可看完整資料與輔導紀錄。

幹部名單 — 對應 Excel「幹部名單」工作表

職務、姓名。匯入 Excel 時會自動帶入，也可以在此手動新增 / 刪除。學生名單會自動顯示每位學生的幹部職務。

IEP — 對應 Excel「IEP」工作表

座號、姓名、性別、程度、報名身分別（詳細描述）、註冊狀況。此區為特教敏感資料，請特別注意保密。

方法一：直接選取你的 Excel 檔案（最推薦）

直接選 115-1資處三忠.xlsx 這個檔案，系統會自動讀取 3 個工作表：班級個人資料 → 學生名單、幹部名單 → 幹部、IEP → IEP。欄位名稱會自動對應，不用手動調整順序。

💡 Excel 裡的文字前面有一個 ' 符號（例如 '呂家羽、'女），是 Excel 強制文字格式，系統匯入時會自動去掉，不會影響資料。
💡 「西元出生」若是 Excel 日期，會自動轉成 YYYY-MM-DD；「學生手機 / 家長手機」會保留原始格式（含 0 開頭與 -）。

方法二：從 Excel 複製貼上（班級個人資料）

在 Excel「班級個人資料」工作表全選 → 複製 → 貼到下方。第一行必須是標題列：科別、姓名、班級、座號、學號、性別、身分證統一編號、報名身分別(原&身)、經濟狀況、出生年、出生月、出生日、西元出生、畢業國中名稱、家長姓名、學生手機、家長手機、電話、郵遞區號、地址。

匯出 / 清除

成績 / 評語 — 匯入每位學生的成績 Excel

每一位學生一份 Excel，例如「呂家羽│二年級歷年成績總表.xlsx」。一次可選多個檔案，系統會自動從檔名 / 標題認出姓名與年級（一年級 / 二年級 / 三年級），存成該學生的成績。同一位學生匯入一年級、二年級、三年級三份，會自動彙總成歷年總表，科目也會跨年彙總。

彙整總表（各年級對照）

每一位學生一列，一年級 / 二年級 / 三年級並排對照：學年平均、上 / 下學期名次、實得學分。這個表會一直保留。

科目彙整（各年級學年成績對照）

上面是全班各科目、各年級的學年成績平均；下面可選一位學生，看他自己的科目在各年級的學年成績對照。這兩個表都會一直保留。

學生照片 — 依座號匯入大頭照

一次可選多張照片。檔名用座號開頭即可認人，例如：01.jpg、01_呂家羽.jpg、1.jpg、07_朱品諺.jpg。如果檔名沒有座號，會再從檔名裡的姓名去對。同一位學生匯入新照片會直接覆蓋舊的。照片會自動縮小、壓縮後保存，不會把 localStorage 塞爆。

使用說明 — 對應你的 Excel

1. 怎麼匯入？
到「匯入 Excel」→ 選取 115-1資處三忠.xlsx → 系統自動讀取 3 個工作表並顯示匯入結果。也可以用複製貼上方式匯入「班級個人資料」。

2. 欄位怎麼對應？
不用自己對欄位。系統會認標題列：科別、姓名、班級、座號、學號、性別、身分證統一編號、報名身分別、經濟狀況、出生年/月/日、西元出生、畢業國中名稱、家長姓名、學生手機、家長手機、電話、郵遞區號、地址。

3. 幹部 / IEP 怎麼看？
匯入後分別在「幹部名單」和「IEP」分頁查看。學生詳情頁也會顯示該生的幹部職務與 IEP 狀況。

4. 個資怎麼保護？
身分證、手機、地址直接顯示完整，不遮罩。不要把匯出的 CSV 傳到群組或公開雲端。

5. 成績 / 評語怎麼匯入？
到「成績 / 評語」→ 一次選多份學生各自的成績 Excel（檔名或標題有姓名與年級），系統會自動認出是誰、哪一年級。同一位學生匯入一年級、二年級、三年級，會自動彙總。詳情頁也會顯示該生的歷年成績。

6. 輔導紀錄怎麼用？
到「輔導紀錄」→ 手動填表，或直接選輔導紀錄 .csv 檔案匯入（第一列是欄位名稱，學號,姓名,發生日期,事件類別,導師輔導內容…，可一次匯入多筆）。讀不到姓名/學號時會自動用你選的學生當備援，不會直接失敗。如果手邊只有文字，請把 CSV 文字貼到框框再按「用這段 CSV 解析」，或直接手動填。

7. 照片怎麼匯入？
到「學生照片」→ 一次選多張照片，檔名用座號開頭即可，例如 01.jpg、07_朱品諺.jpg。照片會自動縮小壓縮後保存，點照片牆的照片可看詳情，也可在詳情頁看到該生的大頭照。

8. 換電腦怎麼辦？
先在舊電腦「匯出 CSV」備份，到新電腦再用「匯入 Excel」選原始 xlsx 重新匯入即可。
